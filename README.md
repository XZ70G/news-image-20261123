## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

The program uses only the Python standard library, needs no network,
and writes a deterministic 1024x1024 PNG to `out/entry.png` (or
`$MAKEFUN_OUTPUT_DIR/entry.png`). Running it twice produces
identical bytes.
